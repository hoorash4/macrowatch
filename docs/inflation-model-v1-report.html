선행지표 보정 규칙

먼저 전월 확정 통합물가에 원자재·달러 가격 변동과 시차별 전가율을 적용해 MacroWatch 선행값을 만든다. Cleveland CPI·PCE 나우캐스트와 원자재 기반 PPI 전망도 같은 통합물가 수준으로 환산한다.

최종 선행값 = 원자재 선행값 + λ × (광범위 나우캐스트 − 원자재 선행값)

괄호 안은 순수 비원자재 물가가 아니라 원자재 경로만으로 설명하지 못한 광범위 예측 차이다. λ는 Headline과 Core에서 따로 정하며, 매월 당시보다 앞선 최근 24개월의 방향 적중률이 가장 높은 값을 다시 선택한다. 검증 구간에서 Headline λ는 0.80~1.00이었고 최신값은 0.80이었다. Core 최신값은 1.00이다.

기대인플레이션은 입력에서 제외한다. CPI·PPI·PCE 실제 발표값은 해당 월 통합물가를 확정하고 다음 달 원자재 선행값의 기준점을 바꾼다.

해석 제한

현재 Cleveland 자료는 각 월의 마지막 발표 전 나우캐스트를 사용하므로 월초의 실시간 성능을 뜻하지 않는다. 운영 전에는 ALFRED 빈티지와 당시 날짜별 나우캐스트로 재검증해야 한다. 나우캐스트의 원자재 반영분을 통계적으로 제거하는 방식도 비교했지만 Headline 방향 적중률이 82.7~86.5%로 낮아져 채택하지 않았다.
